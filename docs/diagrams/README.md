# Диаграммы (актуально на 18.11.2026)

Схемы пересобраны после изменения ролевой модели: HR больше не удаляет и не увольняет,
не правит табель и не создаёт заявки за других; оклад, удаление, увольнение и
self-approve — только `admin`; согласованные заявки неизменяемы; увольнение переводит
сотрудника в архив.
